# Cursor

- Cursor＝Anysphere社のAIファーストIDE。エディタにエージェントを常駐させる開発様式を定着させた
- 最新はCursor 3系（2026年）。複数エージェントを並列で走らせる画面構成へ進化した
- ARR約26億ドル・有料ユーザー約100万人（2026年6月時点）と、AIコーディング専業で最大の商業規模
- SpaceXによる600億ドルの全株式交換での買収が完了（2026年6月発表→同8月クローズ。VC出資スタートアップの買収として史上最大と報道）
- 開発者シェアはGitHub Copilot・Claude Codeとの三つ巴（2026年調査でCopilot 29%・Cursor 18%・Claude Code 18%）
