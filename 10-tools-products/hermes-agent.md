# Hermes Agent

- Hermes Agent＝オープンモデル「Hermes」で知られる米Nous Researchが公開したOSS自律エージェント（2026年2月）
- 特徴は「学習ループ」：タスクを終えるたびに経験からスキルを自動生成・改善し、永続メモリに蓄積する
- モデル非依存で、OpenClawからの移行コマンドを備えるなど、同ジャンルの対抗馬として設計された
- 公開半年でGitHubスター約23万。2026年6月には利用トークン量でOpenClawを逆転したとの報道
- 開発元Nous Researchは評価額15億ドルでの調達交渉が報じられ、OSSエージェントの商業価値を示す例になっている（2026年8月時点）
