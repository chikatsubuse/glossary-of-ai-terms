# GitHub Copilot

- GitHub Copilot＝GitHubのAIコーディング支援。コード補完（2021年）から始まった、この分野の開拓者
- 有料契約470万（2026年1月期決算）・累計利用者2,000万人超で、利用者数では依然として最大級
- 2025年10月の「Agent HQ」で、Claude Code・Codex等の他社エージェントを束ねるハブへ転換
  - 自社完結をやめ「どのエージェントもGitHub上で動かす」プラットフォーム戦略に舵を切った
- 補完型の先行者がエージェント型（Cursor・Claude Code等）に追われる構図で、プロ開発者のシェア低下を示す調査も（2026年8月時点）
