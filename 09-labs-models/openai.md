# OpenAI

- OpenAI＝ChatGPTを生んだAI開発企業。AGIの実現を設立目的に掲げる、業界の代名詞的存在
- 主力はGPTモデル群とChatGPT。動画のSora、コーディングのCodex、ブラウザのAtlasまで製品層が厚い
- 売上ランレート400億ドル超（2026年8月報道）・企業価値8,520億ドル（2026年3月調達時）で、2026年末を目標にIPO準備中
- Microsoftとの排他関係・収益分配を終了（2026年4月）し、Amazon・NVIDIA・SoftBank等から調達する全方位資本体制へ移行
- 次期モデルAstraは、サイバー能力が危険水準に達しうるとして開発を意図的に減速中（2026年8月時点）。競争と安全の緊張を象徴する
