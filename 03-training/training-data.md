# 学習データ／合成データ／アノテーション（Training Data / Synthetic Data / Annotation）

- 学習データ＝モデルの能力の源泉。Web全体・書籍・コードなどから収集される
- アノテーション＝データに人手で正解や評価を付ける作業。合成データ＝AI自身に作らせた学習データ
  - 高品質な人手データは高価で、フロンティア各社はアノテーション専門企業（Scale AI等）に巨額を投じてきた
- モデルの性能差は、構造の差より「データの質と配合」の差で説明されることが増えている
- Web上の良質なデータは採り尽くされつつあり（データ枯渇）、合成データへの依存度が上昇中
