# ローカルとクラウド（Local / Cloud）

- ローカル＝手元の端末（PC・スマホ）の中で処理すること、クラウド＝ネット越しに事業者のサーバーへ送って処理すること
- ChatGPTをはじめ主要なAIサービスはほぼクラウド型。手元のアプリや画面は窓口にすぎず、入力はデータセンターへ送られ、結果が返ってくる
  - だから端末の性能はAIの賢さに関係なく、逆にネットがないと動かない
- 対比の軸：性能と手軽さはクラウド優位。機密データを外に出さない・オフラインで動く・従量課金がない、はローカル優位
- 軽量モデルの進化でローカルの守備範囲は広がり続けており、「どの仕事をどちら側でやるか」の使い分けが実務の設計論点になっている
