# トークン（Token）

- トークン＝LLMが文章を読み書きする最小単位。単語より一段細かい文字列の断片（サブワード）
- トークナイザが文章をトークン列に変換してからモデルに入力する
  - 分割ルールは学習データでの出現頻度から決まり、頻出する文字列ほど1トークンにまとまる（標準手法はBPE）
- API料金も、コンテキストウィンドウ（一度に扱える量の上限・後述）の残量も、文字数ではなくトークン数で数える
  - 同じ内容でも日本語は英語の1.5〜2倍前後のトークンを消費しやすく、費用と入力上限の両方に効く（token tax）
- 日本語語彙の拡張やトークナイザ不要のアーキテクチャなど、言語間の効率差を縮める研究が進行中
