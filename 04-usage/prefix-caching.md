# Prefix Caching

- Prefix Caching＝プロンプトの先頭から共通する部分の計算結果を保存し、次の呼び出しで再利用する仕組み。プロンプトキャッシュとも呼ばれる
- LLMは毎回、入力全体を最初から処理する。会話もエージェントも「同じ長い文脈＋新しい一言」を毎ターン送り直すため、共通部分の再計算が費用と待ち時間の大半を占める
  - そこで前回と同じ接頭辞の処理結果を使い回し、新しい部分だけを計算する
- キャッシュに当たった入力は約9割引が相場（主要3社とも、2026年8月時点）。応答開始も速くなり、エージェント運用のコスト構造を左右する
- システムプロンプトや資料を先頭に固定し、変わる内容を後ろに置くなど、キャッシュが当たりやすいプロンプト設計が実務の定石になっている
