# Azure OpenAI

- Azure OpenAI＝AzureでOpenAIモデルを使う企業向けサービスとして始まった、MicrosoftのAI基盤
- 現在は「Microsoft Foundry」へ再編され、その中の提供モデル群の一つという位置づけに（2025年11月改称）
- 2026年7月にはAnthropicのClaudeも正式提供を開始し、OpenAI専属からマルチモデル基盤へ転換した
- カタログは1万超のモデル（OpenAI・Anthropic・Meta・xAI・自社MAI等）に拡大
- 「OpenAIの独占窓口」がモデル中立の百貨店になった変化自体が、MicrosoftとOpenAIの関係変化の縮図（2026年8月時点）
