# AWS Bedrock

- AWS Bedrock＝AWS上で多社のモデルをAPIとして使えるマネージドサービス。企業のAI導入の標準的な入口
- 18プロバイダ・110超のモデル（Claude・Amazon Nova・Llama・DeepSeek等）を、同じ作法・同じ請求で使える
- 既存のAWS契約・セキュリティ基準のままAIを追加できる「モデルを選べる百貨店」路線が最大の価値
- エージェント実行基盤AgentCoreを2025年にGA。2026年はポリシー制御やエージェントループ構成（Harness）まで管理範囲を拡大
- モデル間競争が激しいほど「どれでも使える場所」の価値が上がるという、クラウド側の勝ち筋を体現する（2026年8月時点）
