# Hugging Face

- Hugging Face＝オープンなAIモデル・データセットの共有ハブ。「AIのGitHub」と呼ばれる業界の共有インフラ
- 公開モデル200万超・ユーザー約1,300万（2025〜26年）。オープンウェイトの流通はほぼここに集中する
- モデル置き場であると同時に、ライブラリ（Transformers等）を通じて学習・推論の共通規格も握る
- 2025年からロボティクスへ進出：買収したPollen Roboticsの製品群と299ドルの小型ロボットで「オープンなフィジカルAI」を推進
- 米中のオープンモデル勢力図の交代がダウンロード数で可視化される、オープンAIエコシステムの中心地（2026年8月時点）
