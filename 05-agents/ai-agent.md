# AIエージェント（AI Agent）

- AIエージェント＝LLMの呼び出しとツール実行を、終了条件を満たすまで自動で繰り返すシステム
- 構成要素は「モデル・ツール群・ループ・終了条件」の4点
  - 毎周回、LLMが次に実行するツールと引数を出力し、システム側がそれを実行して結果を次の入力に加える
  - 「自分で考えて動く」ように見える挙動はこの繰り返しの産物で、意図や責任の主体ではない
- チャットとの本質的な違いは、人間の確認なしに処理が何十回も連鎖すること。権限設計と停止条件が導入検討の中心になる
- 連続処理できるタスクの長さ（人間なら何時間分の仕事か）が急伸しており、能力を測る新しい物差しになっている
