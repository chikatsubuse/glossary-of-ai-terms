# AIブラウザ／ブラウザ拡張（AI Browser / Browser Extension）

- AIブラウザ＝AIが同乗し、ページの要約・比較から操作の代行までするブラウザ。ブラウザ拡張＝既存ブラウザへの後付け版
- 「いま開いているページ」という文脈を共有できるのが、単体チャットとの違い
  - 調べ物の途中でそのまま聞く、複数タブを横断して比較させる、フォーム入力や予約を代行させる等
- 2025年にPerplexityのComet、OpenAIのAtlas等が相次いで登場し、ブラウザの覇権争いが再燃した
- 閲覧履歴という機微データへのアクセスと、Webページ経由のプロンプトインジェクションが安全面の主要論点
