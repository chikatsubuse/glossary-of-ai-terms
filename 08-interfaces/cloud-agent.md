# クラウドエージェント（Cloud Agent）

- クラウドエージェント＝手元の端末ではなく、事業者が用意するクラウド上の隔離環境で動くAIエージェント。バックグラウンドエージェントとも呼ばれる
- 仕事を渡せば端末を閉じても作業が続き、あとで結果を受け取る非同期の任せ方ができる。複数体の並列実行やスマホからの指示もこの形態の売り
- 代表例はCodex Cloud、Claude Codeのクラウドセッション、Cowork、CursorのBackground Agents等（2026年8月時点）
- ローカル実行との使い分けが論点：手元のファイルや環境を直接触るならローカル、環境構築不要で数を並べるならクラウド
- 「対話しながら使う道具」から「預けて待つ委任型」への転換を象徴する形態で、2025年後半以降に各社が標準装備した
